
# capstone_midspot

여러 참여자의 출발 위치를 바탕으로 중간지점을 계산하고, 주변 모임 장소를 추천하는 웹 서비스입니다.

## 프로젝트 소개

약속 장소를 정할 때 한 사람에게 이동 부담이 몰리지 않도록, 참여자들의 위치를 모아 중간지점과 주변 카페를 확인할 수 있는 서비스를 개발합니다.

## 주요 기능

- 모임 방 생성 및 참여 링크 공유
- 참여자 이름과 출발 위치 입력
- 참여자 위치를 바탕으로 중간지점 계산
- 검색 반경 선택 및 주변 카페 추천
- 지도에서 출발 위치, 중간지점, 추천 장소 확인

※ 위 기능은 프로젝트에서 구현할 예정입니다.

## 기술 스택

- **Frontend:** React
- **Backend:** FastAPI
- **Database:** Supabase / PostgreSQL
- **Map & Place Search:** Kakao API

## 프로젝트 구조

- `frontend/` — 사용자 화면 및 프론트엔드 코드
- `backend/` — API 서버 및 데이터 처리 코드

## 브랜치 작업 방식

- `main` — 통합 테스트를 마친 최종 코드
- `develop` — 기능 통합 및 테스트용 브랜치
- 각 팀원은 `develop`에서 기능 브랜치를 만들어 작업합니다.
- 작업이 끝나면 `develop`으로 Pull Request를 생성합니다.
- 통합 테스트가 완료되면 팀장이 `develop`을 `main`에 반영합니다.
